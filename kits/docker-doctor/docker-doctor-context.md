## Docker Doctor

The `docker-doctor` CLI (static analysis for Dockerfiles and Docker Compose files) is installed. After editing any Dockerfile or Compose file, run `docker-doctor` from the project root and fix the reported diagnostics before committing. For the full triage workflow, use the installed `docker-doctor` skill (`/docker-doctor`).

If that skill is not listed, read it at `/opt/docker-doctor/lib/node_modules/@docker-doctor/cli/skill/docker-doctor/SKILL.md`.
